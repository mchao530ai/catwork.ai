請幫我為 Catwork Cafe 建立第一階段 MVP 官網，網域是 catwork.ai。

這個網站的第一階段目標不是做完整電商或完整會員系統，而是先完成以下任務：

讓第一次看到網站的人快速理解 Catwork Cafe 是什麼
提供清楚的來店資訊，降低猶豫
讓使用者可以直接點擊預約、加入 LINE、提交詢問
建立未來可擴充成活動、會員、商品與付款網站的前端基礎

Catwork Cafe 的品牌定位是：
可以和貓一起工作的咖啡空間
風格要結合貓咪、咖啡、共享工作空間、療癒感與日系質感。

一、技術需求

請使用適合在 Replit 快速開發與部署的技術：

Next.js 或 React
響應式設計，手機優先
結構清楚、元件化
SEO 基本友善
後續方便擴充頁面與功能
第一版可使用假資料或本地 JSON 管理內容

請不要做成只有單頁 landing page。
請做成一個有基礎網站架構的正式品牌官網。

二、第一階段只需要完成這些頁面
1. 首頁 Home

首頁需要包含以下區塊：

Hero 區塊：一句清楚說明 Catwork Cafe 是什麼
品牌介紹：可以和貓一起工作的咖啡空間
主要特色：貓咪陪伴、適合工作、Wi-Fi、插座、舒適空間
主要 CTA 按鈕：
立即預約
加入 LINE
查看價格
查看交通方式
空間照片區塊
貓咪介紹預覽
顧客評論預覽
FAQ 預覽
最新消息或活動預覽

首頁要有正式品牌網站的感覺，不要像施工中頁面。

2. 來訪 / 預約頁 Visit / Booking

這一頁是 MVP 最重要的轉換頁，請包含：

地址
地圖區塊
營業時間
特殊公告區
適合工作的環境說明
預約按鈕
LINE 加好友按鈕
第一次來店說明
FAQ 簡版

此外，請加入一個簡單預約表單：

日期
時段
人數
姓名
Email
電話
備註

第一版先做成「提交預約請求」即可，不必串金流。
提交後顯示成功訊息頁或成功提示。

3. 價格頁 Pricing

請做一個簡潔清楚的價格頁，內容可先用示意資料，但要有正式版面。

至少包含：

單次入場
工作時段方案
平日優惠方案
套票預告
月會員預告

每個方案要有 CTA，例如：

立即預約
加入 LINE 詢問
4. 貓咪介紹頁 Cats

請建立一個貓咪總覽頁。

每隻貓至少顯示：

名字
照片
品種
個性標籤
簡短介紹

第一階段不一定要做每隻貓的獨立子頁，但資料結構請保留未來可擴充成獨立頁面。

5. 交通頁 Access

請建立清楚的交通頁，包含：

地址
地圖
從車站怎麼走
開車資訊
停車資訊
周邊地標說明
6. FAQ 頁

請建立 FAQ 頁，至少包含以下問題：

是否需要預約
可以停留多久
有沒有 Wi-Fi
有沒有插座
可以帶電腦工作嗎
可以拍照嗎
貓咪互動規則
小孩是否可入場
如何取消或改期
7. 聯絡頁 Contact

請建立一個正式聯絡頁，包含聯絡表單。

表單用途可包括：

一般詢問
包場詢問
合作詢問

欄位至少包含：

姓名
Email
電話
詢問類型
訊息內容
三、第一階段需要實作的功能
1. LINE 加好友 CTA

請在全站加入明顯的 LINE 導流按鈕，包括：

頁首或固定按鈕
首頁主要區塊
預約頁
頁尾

文案可以是：

加入 LINE 預約
加入 LINE 取得最新活動
加 LINE 詢問空位

LINE 連結先用 placeholder，之後方便替換。

2. 預約表單

請先做成 MVP 表單流程：

使用者填資料
送出後顯示成功訊息
表單元件設計完整
程式結構預留未來串接 Email、Notion、Google Sheets 或資料庫

第一版不需要付款，不需要庫存管理。

3. Email 訂閱區塊

請在首頁或頁尾加入一個簡單 email 訂閱區塊，用來收集名單。

文案方向可為：

訂閱最新活動
接收優惠資訊
追蹤貓咪近況
4. 顧客評論區塊

請加入一個可展示評論的區塊，先用假資料即可。
設計上要有信任感，未來方便替換成真實評論。

5. 最新消息 / 活動預覽區塊

首頁先放簡單卡片區塊，顯示 2–3 則示意活動或最新消息。
第一階段不一定要做完整活動系統，但前端架構要預留。

四、SEO 與基礎設定

第一階段請先做基本 SEO，不要求很完整，但至少要有：

每頁 title
每頁 meta description
Open Graph 基本設定
圖片 alt
語意化 HTML 結構
sitemap
robots.txt
首頁可加入基本 LocalBusiness schema

請讓這個網站至少具備正式商業網站的 SEO 基礎。

五、設計風格要求

請用以下風格設計：

日系
溫暖
乾淨
有療癒感
有咖啡與生活感
不是科技 SaaS 後台風
不是純寵物店風
要有「可以在這裡工作」的成熟感
手機版操作體驗要好
CTA 要明顯但不粗暴

整體要像一個有品牌感、會讓人想實際來訪的空間網站。

六、內容要求

請先幫我填入合理的示意文案與假資料，內容語氣要像正式品牌，不要像 AI 測試頁。

內容主軸請圍繞：

和貓一起工作的療癒感
適合遠距工作與放鬆
第一次來也安心
有特色、適合分享
適合在地客與觀光客
七、資料管理方式

如果第一版不做後台，請至少把資料集中管理，不要把文案硬寫死在元件裡。

請將以下資料獨立管理：

價格方案
貓咪資料
FAQ
評論
聯絡資訊
首頁活動卡片

可以使用 JSON、常數檔案或簡單資料模組。

八、交付內容

請直接產出：

可執行的前端程式
響應式網站頁面
假資料內容
清楚的專案結構
可部署版本
README

README 請說明：

如何啟動專案
如何修改內容
哪些資料目前是示意資料
下一步如何擴充成第二階段功能
九、第一階段先不要做的內容

這一版先不要做太重的功能，以下先保留未來擴充：

真實線上付款
會員登入系統
後台 CMS
複雜座位庫存系統
商品購物車
完整活動報名系統
禮物卡付款流程

但前端結構要保留未來可加上的彈性。

十、成功標準

這個 MVP 完成後，應該要達到以下效果：

看起來像正式品牌網站，不是 placeholder
可清楚說明 Catwork Cafe 是什麼
使用者可以找到地址、價格、交通、FAQ
使用者可以提交預約請求
使用者可以點擊加入 LINE
可作為後續 SEO、活動頁、會員制與銷售功能的基礎
